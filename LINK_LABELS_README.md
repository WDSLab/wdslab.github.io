# Unified link labels
- PAPER / DOI: verified DOI, publisher page, or linked arXiv where no publisher URL exists.
- PUBLICATION DETAILS: jumps to the paper's record in `publications.html` (shown in Home and News; not duplicated on the record itself).
- GITHUB CODE: paper-specific repository when present in existing records.
- NEWS ARTICLE: linked external news article.
- SYSTEM: linked lab platform.
- ARXIV: manuscript link where separately available.
- No links are fabricated; absent links are omitted.
- The original news prose is unchanged.
