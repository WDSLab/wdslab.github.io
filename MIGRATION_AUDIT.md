# WDSLab migration audit

## Included
- 9 site pages plus Gallery.
- 80 publication records, 44 project records, 37 news summaries, and member detail records from the prior migration.
- Existing verified DOI, paper, arXiv and code links preserved, with additional verified paper link corrections.
- Responsive design, image-only cinematic hero and six industrial visual crops.
- Source titles and statuses retained; separate editable JCR/IF CSV template.

## Requires original media access or manual confirmation
- Original member portrait photos, gallery event photographs, and project demonstration videos are not available as standalone source files in this package. **Generated industrial artwork is illustrative, not actual WDSLab project photography.**
- All news bodies and original photo albums were not exported in full; currently some records are summaries.
- Journal metadata is not automatically refreshed. Quartile and IF values should be maintained by the lab.
- DOI/GitHub links not present in the extracted migration cannot be safely invented.
- Korean/English interface support is partial; academic titles retain their original language.
- Verify author lists, journal statuses, email addresses and external links against the source before replacing the existing site.
