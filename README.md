# WDSLab Website

Website of the WDSLab research group, published at https://wdslab.github.io/ by GitHub Pages.
The site is built by Jekyll on GitHub: page layouts live in HTML templates, and the content lives in data files under `_data/`. Pushing to `main` rebuilds and publishes the site.

## Where to edit content

Most updates only touch one file in `_data/`. The homepage and other pages read from the same files, so each item is written once.

| File | Content | Used on |
|---|---|---|
| `_data/news.yml` | News items (date, category, text, links) | Home (latest first), News |
| `_data/gallery.json` | Photo gallery events and photo paths | News (Photo Gallery) |
| `_data/publications.json` | Publications, authors, links, IF / Top % | Publications, Home (Selected Papers), People (counts), dashboard |
| `_data/publication_metrics.json` | IF and Top % used by the publication dashboard | Publications dashboard |
| `_data/people.yml` | Professor profile and members by group | People |
| `_data/research.yml` | Research areas and their selected publications | Home (Research Areas) |
| `_data/projects.yml` | Research projects | Projects |
| `_data/systems.yml` | Services (entries with `image` appear on Home) | Services, Home |
| `_data/navigation.yml` | Top menu | All pages |

Rules:

- Each News item has at most one `News article` link. Selected Papers do not use News article buttons.
- Selected Papers on Home are the publications marked `"selected": true`.
- A member's `name_en` in `people.yml` must match the author name in `publications.json`; the paper count on People is counted from it.
- Paper titles in `research.yml` must match `publications.json` exactly (two papers differ only in letter case).
- `anchor` in `publications.json` keeps an older link address for a paper; do not change it, because News and other pages link to it.
- New photos go in `assets/gallery/` or `assets/members/`; other images, styles and scripts go in `assets/`.

## Pages

All page files are in `_pages/`. Each file's `permalink` sets its address; the build puts `_pages/index.html` at the top of the site as `/index.html`.
`sitemap.xml` and `robots.txt` are generated by the `jekyll-sitemap` plugin.

| Page | File | Address |
|---|---|---|
| Home | `_pages/index.html` | `/` |
| People | `_pages/people.html` | `/people/` |
| Services | `_pages/services.html` | `/services/` |
| Projects (ongoing / completed) | `_pages/projects.html` | `/projects/` |
| Publications | `_pages/publications.html` | `/publications/` |
| News and photo gallery | `_pages/news.html` | `/news/` |
| Contact | `_pages/contact.html` | `/contact/` |
| Not found | `_pages/404.html` | — |

Shared parts:

- `_layouts/default.html` — common page frame (menu, footer, styles, scripts)
- `_includes/` — repeated pieces such as publication records, news items, platform cards and the Research tabs
- `assets/site.css` — site styles (colors, fonts, header, footer); `members.css`, `projects.css`, `services.css`, `publications.css`, `gallery.css` — page styles
- `assets/site.js` — mobile menu, list search/filter/pages, sliding rows; `assets/home.js` — homepage opening scene
- `assets/impact-dashboard.js`, `assets/members.js`, `assets/gallery.js` — publication dashboard, member records, photo gallery
- `_pages/publications.json`, `_pages/publication_metrics.json`, `_pages/gallery.json` — publish `_data/` as `/publications.json`, `/publication_metrics.json` and `/assets/gallery.json` for the scripts above; do not edit them

## Local preview

Install Ruby, then `gem install jekyll`. From this directory run `jekyll serve` and open `http://localhost:4000`.
GitHub Pages builds with its own Jekyll version, so check the published site after pushing.
